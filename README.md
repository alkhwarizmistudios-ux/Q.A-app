# شرائح الأسئلة (Quiz Slides)

تطبيق بسيط شبيه بالبوربوينت، مخصّص لأسئلة الاختيار من متعدد: تكتب الأسئلة وخياراتها وتحدد الإجابة الصحيحة، ثم تعرضها كشرائح بملء الشاشة وتكشف الإجابة وقت ما تريد.

## التشغيل

ملف واحد بدون أي تثبيت أو إنترنت: افتح `index.html` بأي متصفح (Chrome, Edge, Firefox, Safari).

## الاستخدام

### 1. التحرير
- **عنوان العرض** في الأعلى.
- **+ سؤال جديد** يضيف سؤالاً بعد السؤال الحالي.
- لكل سؤال: نص السؤال، من 2 إلى 6 خيارات، واختيار **الدائرة** بجانب الإجابة الصحيحة (يتلوّن الخيار بالأخضر).
- **شرح الإجابة** اختياري ويظهر تحت الخيارات عند كشف الإجابة.
- أزرار السؤال: ▲ ▼ لإعادة الترتيب، ⧉ للنسخ، 🗑 للحذف.
- القائمة الجانبية تنبّهك (⚠) لأي سؤال ناقص.

العمل يُحفظ تلقائياً في المتصفح. للاحتفاظ بنسخة أو نقلها لجهاز آخر استخدم **حفظ كملف** (JSON) و **فتح ملف**.

### 2. العرض
اضغط **▶ بدء العرض**: شريحة عنوان، ثم شريحة لكل سؤال، ثم شريحة ختام. الأسئلة الناقصة تُتخطّى.

| المفتاح | الوظيفة |
|---|---|
| ← أو Enter أو PageDown | الشريحة التالية |
| → أو Backspace أو PageUp | الشريحة السابقة |
| مسافة (Space) | إظهار / إخفاء الإجابة الصحيحة |
| Esc | الخروج من العرض |

يعمل أيضاً مع أجهزة التحكم بالعروض (Presenter clicker) لأنها ترسل PageUp/PageDown.
